2- validation on the input filed (field invalide) 

if we are not touch or input we can not submit 

- we build one function to get the input field then

  isInvalid(path: string): boolean{
    // this function return boolean true or false 
    const ctrl = this.form.get(path);
    return !!ctrl && ctrl.invalid && (ctrl.touched || this.submitted);
  }


Explian : 

- !!ctrl សញ្ញា !! ពីរដង់នឹងវានឹងសួរថា តើវាមានអត់ តើតម្លៃវា Null or undefine or not
