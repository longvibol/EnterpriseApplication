- Want to find the nearest from our current location to the destination 

- in the mongodb we store in the Point(lat,log)

- ដើម្បី Search បានយើងត្រូវបង្កើត file : GeoJsonPoint for the Mongodb 

1 - We put it in the Room.java (domain)
---------------------------------
  /**
   * GeoJSON Point for geo queries.
   * Mongo expects coordinates in order: [longitude, latitude].
   */

  @GeoSpatialIndexed(type = GeoSpatialIndexType.GEO_2DSPHERE)
  private GeoJsonPoint geoPoint;

---------------------------------

- geoPoint : have two property : type and coordinate (it is object)

Ex:  geoPoint: { type: "Point", coordinates: [104.9282, 11.5564] }

2 - Create dto for output :

----------------------------------------------------
